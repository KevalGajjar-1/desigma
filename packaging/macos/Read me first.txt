desigma - install and first launch
==================================

1. Drag desigma into the Applications folder (the arrow in this window).
2. Open Applications and double-click desigma.
3. The first time, macOS says it cannot verify the app. This is because the
   build is not notarized by Apple yet (the source is public and the release
   is built by GitHub Actions). Click Done, then:
     - open System Settings -> Privacy & Security,
     - scroll down to the message about "desigma" and click Open Anyway,
     - confirm with your password or Touch ID, then click Open.
   You only need to do this once.

Prefer Terminal? This does the same thing in one line:

    xattr -dr com.apple.quarantine /Applications/desigma.app

Command-line tool
-----------------
desigma-diff is inside the app. Run it from Terminal with:

    /Applications/desigma.app/Contents/MacOS/desigma-diff --help

or link it onto your PATH:

    ln -s /Applications/desigma.app/Contents/MacOS/desigma-diff /usr/local/bin/desigma-diff
